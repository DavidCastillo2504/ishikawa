# Arquetipo sistémico para operación de servicios TI

Página web en React/Vite que presenta un caso práctico de gestión técnica mediante:

- Diagrama de Ishikawa interactivo.
- 18 causas distribuidas en 6 categorías.
- Criticidad 1–5 basada en Probabilidad × Impacto.
- Matriz de riesgo 5×5.
- Panel de detalle por causa.
- Explicación del arquetipo sistémico **Desplazamiento de la carga**.
- Registro priorizado y buscador.

## Ejecutar

```bash
npm install
npm run dev
```

Abre la dirección local que muestre Vite (normalmente `http://localhost:5173`).

## Compilar

```bash
npm run build
npm run preview
```

## Escala usada

- 1: riesgo bruto 1–4
- 2: 5–8
- 3: 9–12
- 4: 13–19
- 5: 20–25

> El caso y sus métricas son simulados para fines académicos.
